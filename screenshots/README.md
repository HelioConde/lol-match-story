# Screenshots automáticos

Estas imagens são geradas pelo workflow `Capture Full Page Screenshots`.

Arquivos:
- `latest-home-full.png`: página inicial inteira em desktop.
- `latest-story-full.png`: página inteira com a história demo aberta em desktop.
- `latest-mobile-full.png`: história demo inteira em viewport mobile.
- `metadata.json`: commit e data da captura.

O workflow roda automaticamente quando arquivos visuais/funcionais principais mudam e também pode ser executado manualmente em **Actions → Capture Full Page Screenshots → Run workflow**.

Isso permite revisar a evolução visual do site diretamente pelo histórico do GitHub.
